# PotatoesPortfolio

Portfolio site for Karthika Vinod — B2B social media, content strategy and storytelling.

## Structure
- `index.html` — site content
- `styles.css` — layout, responsive styling and animation
- `script.js` — scroll reveals, counters, interactions and case-study modal

## Publishing with GitHub Pages
This repository is designed as a static GitHub Pages site. In GitHub:
1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select **main** and **/(root)**
4. Save

## Content note
The monthly newsletter case study intentionally has no public sample link yet. Add one in `index.html` and `script.js` when a final newsletter example is selected.
